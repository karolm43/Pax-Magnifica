## Rules Reference

Frontier tokens can be explored for a variety of game effects.

- Frontier tokens are placed on the game board during setup. One frontier token is placed in each system that does not contain any planets.
    - Frontier tokens are not placed on hyperlane tiles.
    - A system cannot have more than one frontier token.
    - Frontier tokens are placed in anomalies that do not have planets.
    - A frontier token is placed in the [Creuss gate](https://twilight-imperium.fandom.com/wiki/The_Ghosts_of_Creuss#Faction_Abilities:~:text=Creuss%20gate) system.

## Notes

- Players may explore space areas that contain frontier tokens if they own the *Dark Energy Tap* technology or if another game effect allows them to.
- If a system tile contains a space station, but no planets, then a frontier token will be placed in that system during game setup.
- Frontier tokens are not placed in systems in The Fracture when it is brought into play, as frontier tokens are only placed during setup. However, if The Fracture is in play when the [Empyrean](https://www.tirules2.com/F_empyrean) player resolves their [*Multiverse Shift*](https://twilight-imperium.fandom.com/wiki/The_Empyrean#Leaders:~:text=Multiverse%20Shift) hero ability, frontier tokens will be placed in the systems in The Fracture that do not contain a planet.
- If [Thunder’s Edge](https://twilight-imperium.fandom.com/wiki/Thunder's_Edge) is placed in a system containing a frontier token, that token is not removed.
