## Rules Reference

There currently does not exist a Living Rules Reference section regarding neutral units.

## Notes

- Neutral units are placed in some systems within The Fracture when it enters play. Several other game effects also place neutral units.
- If a player has ships in a space area that contains neutral units, they will resolve a space combat against those units.
- If a player has ground forces on a planet that contains neutral units, they will resolve a ground combat against those units.
- Any player other than the active player may roll the combat and unit ability dice during a combat involving neutral units. The combat values and unit abilities are found on the neutral unit reference card.
- Neutral units will always use each and every unit ability that they can.
- Neutral units do not take turns, own technology, or draw action cards, and so on.
- When a hit is assigned against a group of neutral units, it is assigned to the unit that is lowest on the neutral unit reference card.
- Neutral units are considered to be another player’s ships for abilities and other game effects. However, there is no neutral player.
- Neutral units with `Sustain Damage` use it to cancel hits before any remaining hits are assigned. For example, if a neutral destroyer and a neutral dreadnought take one hit, the dreadnought uses `Sustain Damage` to cancel it.
- Neutral units cannot make decisions. If a decision must be made for a neutral unit, the speaker makes it.
    - During combat, hits against neutral units are always assigned in the order on the neutral unit reference card, so the speaker does not choose. The speaker does choose which neutral units are hit outside of combat, such as by `Space Cannon`.
- If there are no neutral units of a given type left in the supply, and one would be placed, it is not placed.
