## Blood Pact (Promissory Note)

- Both players must cast at least one vote to trigger the additional votes.*
    - If either player cannot vote on an agenda, then the additional votes will not trigger for that agenda.
- *Blood Pact* is returned when the system is activated, even if the active player will perform no hostile acts toward the Empyrean player this turn.*
- Activating a system containing only the Empyrean player’s structures will still cause *Blood Pact* to be returned.*
- If an effect other than activating a system during a tactical action places a command token in a system with the Empyrean player’s units (for example, the primary ability of the *Diplomacy* strategy card), this will not cause *Blood Pact* to be returned.*

## Dark Pact (Promissory Note)

- A player cannot have more commodities than their commodity value.
- If the Empyrean player plays a player’s *Trade Agreement* promissory note, this will count for that player giving the Empyrean player all their commodities.*
- The trade goods gained from *Dark Pact* are gained simultaneously with the commodities transacted between the two players.
- As the trade goods from *Dark Pact* are gained simultaneously with any commodities and/or trade goods transacted, the [Mentak](https://www.tirules2.com/F_mentak) player may only use their [`Pillage`](https://twilight-imperium.fandom.com/wiki/The_Mentak_Coalition#Faction_Abilities:~:text=Pillage) ability on each player once per *Dark Pact* transaction.
- *Dark Pact* is returned when the system is activated, even if the active player will perform no hostile acts toward the Empyrean player this turn.*
- Activating a system containing only the Empyrean player’s structures will still cause *Dark Pact* to be returned.*
- If an effect other than activating a system during a tactical action places a command token in a system with the Empyrean player’s units (for example, the primary ability of the *Diplomacy* strategy card), this will not cause *Dark Pact* to be returned.*

## Aetherstream (Technology)

- The Empyrean player does not decide to use this ability until after the other player has activated a system. Any deal made to use this ability before the system has been activated is non–binding.
- If a system is separated from an anomaly by the Empyrean player’s [Void Tether](https://twilight-imperium.fandom.com/wiki/The_Empyrean#Breakthrough:~:text=Void%20Tether) token, *Aetherstream* can only be used for that system if the Empyrean player allows it. This includes the [Nekro](https://www.tirules2.com/F_nekro) player using a copy of *Aetherstream*.

## Voidwatch (Technology)

- The active player chooses which promissory note they give the Empyrean player.*
- Giving a promissory note because of *Voidwatch* is not resolving a transaction.*

## Dynamo (Flagship)

- A unit may only use its `Sustain Damage` ability once in each timing window, even if it is repaired.
- A unit that becomes damaged without using its `Sustain Damage` ability will not trigger this effect.*
- A player may play a *Direct Hit* action card during the same timing window as this ability. If they do so, the ship is destroyed.
- Influence must be spent separately for each use of this ability. As such, any excess influence used to repair a ship is wasted, and cannot be used to repair a different ship.
    - As an example, The Dark may be exhausted to repair only one ship, not two.*

## Acamar (Agent)

- A system that contains a planet destroyed by the *Stellar Converter* relic, and no other planets, is considered to contain no planets.

## Xuange (Commander)

- While the agenda phase allows a player to resolve transactions with all other players, it does not make that player neighbors with all other players.
- Any movement of ships can trigger this ability, not just movement during the **Move Ships** step of a tactical action.*
- If the Empyrean player becomes neighbors with all players when the final player moves ships into a system containing one of the Empyrean player’s command tokens, Xuange will unlock, but the Empyrean player will not be able to resolve its ability from that movement.
- If the Empyrean player moves a ship into a system containing one of the [Saar](https://www.tirules2.com/F_saar) player’s Floating Factories, and no other ships, that [Floating Factory](https://twilight-imperium.fandom.com/wiki/The_Clan_of_Saar#Space_Dock:~:text=Floating%20Factory) will be blockaded and destroyed before the Empyrean player can unlock Xuange. If the Empyrean and Saar players are not neighbors in any other way, then Xuange will not unlock.
- Only the system in which a ship ends its movement is “moved into”; systems a ship moves through are not. As such, Xuange returns at most one command token for each movement.

## Conservator Procyon — Multiverse Shift (Hero)

- A system that contains a planet destroyed by the *Stellar Converter* relic, and no other planets, is considered to contain no planets.
- If The Fracture is in play when the Empyrean player resolves *Multiverse Shift*, frontier tokens will be placed in the systems in The Fracture that do not contain a planet.

## Watcher (Mech)

- This effect may cancel a *Sabotage* action card.
- The Watcher must be adjacent to the other player’s units during the timing window when the action card is played in order to cancel it.*
    - In particular, if an action card is played “when/after you activate a system” or similar, then the Watcher must be adjacent before any ships move during that tactical action.*
- If an action card is canceled by a Watcher, no costs are paid.*
- A player playing an action card announces the following before a Watcher may be triggered:*
    - Any targeted planets, system, units, players, cards, outcomes, and/or other such objects.
    - The value of any variable cost to be paid.
- Any dice are rolled and any cards are drawn only after the Empyrean player has declined to remove a Watcher.*
- If an action card instructs a player to research a technology, that player need not announce what technology they are researching until the Empyrean player has declined to remove a Watcher.*
- If an action card is played that will have an effect later, such as a rider, that card may only be canceled by a Watcher when it is originally played.*
- If the action card that was canceled by a Watcher was to be used to perform a component action, the active player must perform a different action, or pass.
    - If the component action was to be the second action the active player was to perform on their turn, through an effect such as the *Fleet Logistics* technology, the active player may end their turn without performing a second action and without passing.

## Void Tether (Breakthrough)

- Other players treat the systems that share the border with the Void Tether token as not being adjacent for all game effects, even if both systems contain matching wormholes. The Empyrean player continues to treat them as adjacent.
    - If the Empyrean player has units or controls a planet in one of the systems, they will be neighbors with any player with units or controlling a planet in the other, and vice versa.
- If the Empyrean player is eliminated, *Void Tether* remains in play, and the Void Tether tokens continue to function.
