# Active System

## Rules Reference

The active system is the system that is activated during a tactical action.

- When a player performs a tactical action, they activate a system by placing a command token from their tactic pool in that system. That system is the active system.
- A player **cannot** activate a system that already contains one of their command tokens.
    - (Thunder’s Edge) The primary ability of the *Warfare* strategy card allows a player to perform a tactical action in a system that already contains one of their command tokens, without placing a command token.
- A player **can** activate a system that contains command tokens that match other players’ factions.
- A system remains the active system for the duration of the tactical action during which it was activated.

## Notes

- A system is only activated by placing a command token during the Activation step of a tactical action or through the primary ability of the Warfare strategy card. Command tokens placed by other effects, such as the primary ability of the *Diplomacy* strategy card or a retreat, and action cards that target a system, do not activate that system.
