## 16. Faction Starting Technology Selection — ✅ VERIFIED (data)

📎 tirules: [Technology](../../../../rules_tirules/R_technology.md) · [Technology (Strategy Card)](../../../../rules_tirules/R_technology_sc.md)

Source: AsyncTI4 faction data (`assets/data/factions/*.json`), fields `startingTechOptions`
+ `startingTechAmount`. Verified 2026-10 on active sources.

Most factions have FIXED starting technologies (`startingTech`). Some DO NOT have fixed ones —
the player CHOOSES ``startingTechAmount`` technologies from ``startingTechOptions``:

| Faction | Amount | Options (alias) |
|---|---|---|
| Winnu | 1 | amd, det, nm, pa, st, sdn, ps, aida (any 1) |
| Argent Flight | 2 | nm, st, ps |
| Last Bastion (TE) | 1 | amd, det, st, sdn |
| The Firmament (TE) | 1 | nm, pa, st, sdn |
| The Crimson Rebellion (TE) | 1 | det, amd, ps, aida |
| The Ral Nel Consortium (TE) | 1 | nm, pa, ps, aida |

Implementation: `faction_setup.resolve_starting_tech` (validation of count and allowed
options) + choice passed via `starting_tech` in the setup/new-game request; UI displays a
menu to choose N from the list when `startingTechAmount > 0`.

### 16a. Deferred Technology Selection: Keleres and Deepwrought — ✅ VERIFIED (tirules)

📎 tirules: [Council Keleres](../../../../rules_tirules/F_keleres.md) (The Tribunii) ·
[The Deepwrought Scholarate](../../../../rules_tirules/F_deepwrought.md) (Research Team)

Two factions choose their starting technologies NOT during setup, but LATER — in-game, after
ALL other players have received their starting technologies:

- **The Council Keleres** (`keleresm`/`keleresx`/`keleresa`) — "The Tribunii" rule: chooses
  UP TO 2 non-faction technologies OWNED by other players (if 2 unique ones do not exist,
  starts with fewer). In data: `startingTech=[]`, no options → `startingTechAmount=0`.
- **The Deepwrought Scholarate** (`deepwrought`) — "Research Team" ability: "research
  technology twice" (any 2 technologies from the start of the tree, following prerequisites).
  In data: `startingTechAmount=2`, but `startingTechOptions=[]` (EMPTY).

Implementation status:
- `resolve_starting_tech` treats "amount > 0 with an empty options list" as a faction
  with deferred selection → returns `[]` (starts with no tech), instead of an error/fallback.
- Setup UI (`frontend/.../setup/deferredTech.ts`) classifies these 4 IDs as "deferred":
  does not show a selection panel, only a message (in English) that selection will occur in-game
  before the 1st agenda phase; validation does not require them and `starting_tech` is not sent.
- ⚠️ ASSUMPTION / TODO: the actual DEFERRED in-game selection (timing window after all players
  are set up; for Keleres reading other players' technologies + prerequisites for
  Deepwrought) is NOT yet coded — for now, the operator grants these technologies
  manually (God-Mode). To be implemented at the appropriate engine stage (timing windows).
