### 62.0 "During/After X: you may…" Abilities Used on Player Initiative
A component without an `ACTION:` header that the player uses on their own during a given step (not an event reaction) registers a window condition `faction_components.window_use(kind, id)` — the function returns a refusal reason or `None`. Such a component is played via `POST /faction-component/play` like an ACTION, but does NOT consume a turn action (effect + cost per 61.3). UI: same `FactionComponentUseModal`. ✅ User decision (2026-11-12): such abilities POP UP AUTOMATICALLY — `faction_components.available_now` + `GET /faction-component/available-now` (own over network, all humans locally) → "Available now" card (`domains/offers/AbilityPrompts`, bottom-left corner) with Use button; "Not now" hides it until the window closes. Leader menu remains as a secondary path.
