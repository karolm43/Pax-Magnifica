## 9. Action Phase Turn Order and Pass — ✅ VERIFIED

📎 tirules: [Initiative Order](../../../../rules_tirules/R_initiative_order.md) · [Action Phase](../../../../rules_tirules/R_action_phase.md) · [Active Player](../../../../rules_tirules/R_active_player.md) · [Strategy Card](../../../../rules_tirules/R_strategy_card.md)

Source (not from memory): AsyncTI4 bot, `EndTurnService.findNextUnpassedPlayer` +
`Game.getActionPhaseTurnOrder`. Rules:
- **Initiative order:** players ordered by strategy card number (initiative),
  ascending (lowest number first). Without cards → stable order (by player id).
- **Next player:** after ending a turn, advances to the next player in order
  who has NOT passed and is not eliminated (list rotation past the current player).
- **Pass:** a player passes → is skipped until the end of the action phase. When all have passed →
  the action phase ends (transition to the status phase).
- **New round:** passes reset; phase returns to strategy, round +1.

Implementation: `src/core/turn_flow.py` (pure functions) + endpoints
`/turn/end`, `/turn/pass`, `/phase/next`, `/round/next` in `app.py`.
