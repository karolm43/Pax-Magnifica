> ⚠️ **DIRECTION UPDATE (see Section 29):** annotations `does NOT validate` / `assistant, not a referee` in this section are SUPERSEDED. The content remains accurate as a REFERENCE for TI4 mechanics; rule enforcement moves into `core/` per 29.1.


Stage E3. The application does NOT validate production limits or spending — it is a numerical helper.
`core/tactical.production_help(state, registry, player_id)` computes:
- **available resources** = sum of `PlanetDef.resources` of planets controlled by the player
  (`planet_owners`), from the registry (not from memory);
- **player unit cost** from `UnitDef.cost` (faction/upgraded variant based on technology —
  `combat.resolve_unit_variant`, consistent with RULES.md 10/20).

**Dual production** (2 units for a single cost): fighter, infantry — LRR rule
"Producing Units"; kept as an explicit `_DUAL_PRODUCTION` table (cost data from `UnitDef`).
Unit placement is done by the operator via God-Mode (`edit-units`); production is only a hint.
