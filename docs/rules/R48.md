## 48. Game end: round limit and epilogue (honorable / dishonorable vote) — ⚠ ASSUMPTION (design rule, NOT from TI4)

Source: user decision (2026-11-08). VP threshold and tiebreaker: `R_victory_points` (tirules2.com).

- The game ends immediately upon reaching `vps_to_win` points (`end_reason = "victory_points"`) —
  this is a TI4 rule.
- ⚠ **Round limit**: after the end of round `max_rounds` (default 10; 0 = unlimited), the game
  ends and the VP leader wins (tie → first in initiative order, per `R_victory_points`;
  `end_reason = "round_limit"`). The agenda phase of the boundary round is skipped. This is a house rule.
- ⚠ **Epilogue**: after the game ends, all players EXCEPT the winner vote on whether the victory was
  honorable or dishonorable. Secret ballot until all votes are in; majority decides,
  **ties are broken by the second-place player's vote** (highest VP excluding the winner). Bots vote automatically (deterministic placeholder pending AI).
  The result selects the winner's faction epilogue card (`frontend/src/domains/victory/factionEpilogues.ts`).
- Code: `core/epilogue.py`, `api/routers/epilogue.py` (`/epilogue/open`, `/epilogue/vote`),
  `core/status_phase.finish_status` (round limit).
