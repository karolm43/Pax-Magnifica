📎 tirules: [Planets](../../../../rules_tirules/R_planets.md) · [Resources](../../../../rules_tirules/R_resources.md) · [Influence](../../../../rules_tirules/R_influence.md)

Source (not from memory): AsyncTI4 bot, `Planet.getOptimalResources/getOptimalInfluence/
getFlexResourcesOrInfluence`. Rule per controlled planet:
- `optimalResources` = `resources` when `resources > influence`, else 0;
- `optimalInfluence` = `influence` when `influence > resources`, else 0;
- `flex` = value (res==inf) when `resources == influence`, else 0.
Sums across the player's planets feed `playerData.optimalResources/optimalInfluence/flexValue`
(and `tot*`). `resources`/`influence`/`totResources`/`totInfluence` = raw sums.
Implementation: `src/api/web_data.py` → `_planet_economy` / `_Economy`.
