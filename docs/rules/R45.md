## 45. Initial setup: secret objectives, promissory notes, Custodians token, public objectives — ✅ VERIFIED (tirules2.com) + ⚠ ASSUMPTIONS

Source: `rules_tirules/R_objective_cards.md`, `R_mecatol_rex.md`, `R_custodians_token.md`, `R_promissory_notes.md`. Code: `core/game_setup.py`, `api/routers/setup.py`, `api/web_setup.py`, UI `frontend/src/domains/setup/GameSetupOverlay.tsx`.

### 45.1. Rules
- (S1) The game has **five** Stage I and **five** Stage II public objectives, face down; the speaker reveals **two Stage I objectives** (R_objective_cards). The remaining eight stay face down until the status phase.
- (S2) During setup, the Custodians token is placed on Mecatol Rex (R_mecatol_rex). Removal: RULES.md 41 / R_custodians_token.
- (S3) Each player starts with a hand of promissory notes: **5 generic** (`<color>_*` templates from the catalog: Ceasefire, Political Secret, Support for the Throne, Trade Agreement, Alliance) in the player's color + **1 faction** (`faction.promissory_notes`).
- (S4) Each player starts with one secret objective (R_objective_cards).
- (S5) Frontier tokens (R_frontier_tokens): during setup, **one** token in each system **with no planets** — empty space, anomalies with no planets, wormholes, as well as **Creuss Gate** (17) and **The Sorrow** (94). **Not** on hyperlane tiles. At most one token per system.

### 45.2. ⚠ ASSUMPTION (user decision)
- The tirules dump says "each player starts with one secret objective" and does not describe drafting. Per user decision, each player **draws 2 secret objectives, keeps 1, and returns the other to the deck (deck is shuffled)** — just like in the board game rulebook. Hence the `SECRETS` stage.

### 45.3. Implementation
- `GameState.setup: SetupState | None` (`stage` ∈ `SECRETS|CUSTODIANS|OBJECTIVES`, `secrets_chosen`, `custodians_placed`); `None` = setup completed (also for states created outside `/game/new`).
- `PlayerPrivateState.secret_candidates` — the two drawn objectives (private; visibility redaction works automatically).
- `objectives.setup_objectives(..., interactive=True)`: 5+5 face down, 2 candidates per player; default mode (tests) preserved.
- `/game/new` → `begin_setup` (decks, promissory note hand, bots choose randomly). Selection queue = seating order; `active_player_id` = chooser, then speaker.
- Endpoints: `POST /setup/secret`, `/setup/custodians` (speaker only), `/setup/reveal-objectives` (speaker only; ends setup and passes the turn to the first strategy card picker).
- `strategy_phase.pick_strategy_card` rejects picking a card while `state.setup` is not `None` (engine-as-referee).
- web-data: `gameState.setup`; Custodians token as a token on planet `mr` under the `neutral` key while on the board (`web_setup.custodian_on_board`).
- Frontier: `SystemState.frontier_token: bool`; `game_setup.place_frontier_tokens(state, grid, registry)` called in `/game/new` (systems from the registry without `planets`, excluding the name "Hyperlane"). web-data: `frontier` token in `space` under the `neutral` key. Token removal via exploration (Dark Energy Tap) — TODO in RULES.md 46.
- **Secret objective selection is simultaneous** (as at the table: everyone draws 2 and keeps 1 at the same time; order has no rules impact). `choose_secret` accepts a choice from any player in `game_setup.pending_choosers` (has not chosen yet); a second choice by the same player → 422. `current_chooser` (first in seating order) remains only as the single-screen view queue.
- web-data `gameState.setup` computed from the FULL state: `pending` (who is still choosing — public), `simultaneous`, `candidatesFor` + `candidates`. Network game (strict projection): only the viewer's candidates while they are still choosing. Single screen / host-operator: `chooserId`'s candidates.
- `core/actor.awaiting` during setup: `secret` for each player in `pending_choosers`, then `setup` for the speaker.
- UI: single screen / host test mode — fullscreen overlay with a "pass the screen" gate one by one. Network game — everyone sees their 2 cards immediately, and after choosing sees the list of who we are waiting on; Custodians/reveal stages can only be clicked by the speaker (others wait, but see cards being flipped); "Skip setup" host only.
