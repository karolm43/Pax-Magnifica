### 37.2. Known Reference Gaps (Homebrew — Documented, Not Defects)

The auditor detects 22 unresolved references. **All originate from homebrew content**,
which despite its non-canonical source references components not loaded by the registry.
They are intentionally documented here as known and do NOT block further coding of
canonical rules (pending final user confirmation):

- **`explores_cpti`** (homebrew deck "cpti") — 18 `deck.cardIDs` entries pointing to
  non-existent cards (`fiveac1..3`, `fivetg1..3`, `freetech1..3`, `gain*agent`, `kel3`).
  Flag `leaks_noncanonical=True` (homebrew leak, R7.6). The deck is non-canonical —
  to be excluded or ignored.
- **`mirage`** — `exploration.attachmentId='mirage'` → missing attachment `mirage`
  (homebrew / unloaded variant).
- **`gamma`** and **`gw`** — `exploration.attachmentId='gamma'` → missing attachment `gamma`
  (homebrew "gamma wormhole" anomaly).
- **`ion`** — `exploration.attachmentId='ionalpha'` → missing attachment `ionalpha`
  (homebrew "ion storm").

Recommendation: treat these references as fan-content leakage. Ultimately, a source filter
or excluding homebrew decks will remove them from the report; until then, they are listed here
so the audit is not "red for an unknown reason".

### 37.3. Data Anomaly: `codex1` Entry in `theodisi.json` — ⚠️ ASSUMPTION (to confirm)

The auditor marks as "suspicious" entries with a Canonical Source located in files whose name
indicates homebrew (R4.5). Key case: an action card with `source=codex1`
in the homebrew file `theodisi.json`. **Adopted behavior (D6):** the entry IS LOADED
(filtering operates on the `source` field, not the filename), so it enters the catalog as
canonical `codex1`. This is an ⚠️ ASSUMPTION — pending user confirmation on whether this is
a real Codex 1 card or a mislabeling in the homebrew file.

### 37.5. Refreshing the Counts

The current snapshot is generated with a single command:

```bash
uv run python -m src.audit --json        # counts + statistics in JSON

```

After changing counts (new source, errata), update the baseline and this summary together.
