### 41.1. Objective Setup (R_objective_cards)
- (O1) The game has **five** Stage I objectives and **five** Stage II objectives (facedown, drawn from decks). The speaker **reveals two Stage I objectives** during setup; the rest stay facedown.
- (O2) Each player starts with **one secret objective**. Limit: **3** secret objectives total (scored + unscored).
- (O3) Objective stage = the deck it originates from (`public_stage_1/2_objective`); points from card (I = 1 VP, II = 2 VP).

### 41.2. Eight Steps of the Status Phase (R_status_phase)
1. **Score Objectives** — in initiative order, each player may score ≤ 1 public objective and ≤ 1 "Status" phase secret objective. Each objective only once per game; the same objective may be scored by multiple players. Scoring a public objective requires controlling EVERY planet in the player's home system (space stations do not count).
2. **Reveal Public Objective** — the speaker reveals the next objective; Stage II objectives only after all Stage I objectives are revealed. No facedown objectives at the start of this step → **game ends** (most VPs wins, tie → first in initiative order).
3. **Draw Action Cards** — each player draws 1 card (in initiative order). If deck runs short: players LOWEST in initiative first, then shuffle discard pile and draw the rest.
4. **Remove Command Tokens** — tokens on the board return to reinforcements (`cc_reinf`).
5. **Gain and Redistribute** — each player gains 2 tokens from reinforcements (fewer if reinforcements are smaller) and redistributes ALL tokens among strategy/tactic/fleet pools. Reducing fleet pool requires checking ships (R_fleet_pool: ≤ as many non-fighter ships in a system as tokens in fleet pool).
6. **Ready Cards** — planets, technologies, leaders (agents), breakthrough, and strategy cards return to the ready state.
7. **Repair Units** — all damaged units are repaired (including those without Sustain Damage).
8. **Return Strategy Cards** — cards return to the common pool. If the **Custodians token has been removed** → proceed to Agenda Phase, otherwise start a new round from Strategy Phase.

### 41.3. Victory Points (R_victory_points)
- (V1) The game ends immediately when a player reaches `vps_to_win` (10; 14 on the other side of the track). Tie at threshold → first in initiative order.
- (V2) Scoring a public objective: the player places a control token on the card and advances by the card's points; a secret objective is **revealed** when scored.

- `core/objectives.py` — deck setup (`setup_objectives`, called in `/game/new`), `reveal_next_public`, `score_public/secret`, `controls_home_planets`, `award_points`.
- `core/status_phase.py` — steps: `score_objective`, `finish_scoring` (after last player, auto steps 2–4 + gain tokens), `redistribute` (after last player, auto steps 6–7 → `COMPLETE`), `finish_status` (step 8 = speaker's `/phase/next`), `complete_status` (test mode `/phase/skip`).
- `turn_flow.next_phase` on entering STATUS initializes `status` (unit repair NO longer happens immediately on entry — it is step 7). `can_advance_phase` in initialized status = `step == COMPLETE`. `/turn/phase-step` in initialized status → 422. Status entered via God-Mode (`status = None`) follows the legacy path (passes → `next_phase`).
- Strategy cards return in step 8 (TGs on unpicked cards added BEFORE return), so `/round/next` after Agenda uses `strategy_phase.close_round_cards` (no-op if cards were already returned).
- API: `POST /status/score`, `/status/finish-scoring`, `/status/redistribute`; `POST /phase/next` in status = step 8. Web-data: `objectives` (Stage I/II tables + "other points", unrevealed objectives as `UNREVEALED_*`), `scoreBreakdowns` (point track per player), `gameState.status`, `gameState.winner/winnerId`, `playerData.secretsScored/knownUnscoredSecrets`.
- UI: `StatusPhasePanel` (8 steps, scoring, token redistribution), existing AsyncTI4 modules (objective tables below map, `PlayerScoreSummary`) now fed by real data.
